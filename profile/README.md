# Uninstall Tool - A Maintained List of Desktop Software

## At a Glance

The Windows settings list is enough for one removal a month. It is a poor ledger when you install and remove often, or when you want install dates and leftover checks in the same place. Uninstall Tool is that ledger. You see the desktop products, you run their uninstall commands, and you can keep an install log if monitoring was on when they were added.

- Sort by name, size, or date  
- Batch removal for a selection you actually reviewed  
- Install monitoring for setups you still intend to make  
- Leftover scan after the official uninstall  
- A resident monitor only if you want that log later  

## Monitoring Is Optional

Turn monitoring on if this is your own PC and you want tomorrow's uninstall to know what today's setup wrote. Leave it off if you are visiting a machine solely to remove three toolbars. Installing a monitor to delete software adds a component the owner did not ask for. The uninstaller half works without the monitor; you just will not have a trace for programs that are already present.

When monitoring is on, install one product at a time so the log stays separable. A log that covers an evening of random setups will suggest a combined leftover set later. That is the same failure as any tracer: the record is only as tidy as the installs.

## Batch Removal

| Selection | Acceptable | Not acceptable |
|---|---|---|
| Three toolbars you opened and recognized | Yes | Adding every unknown publisher |
| Old games the owner named | Yes | Anything with "runtime" in the name |
| A VPN you are replacing | Yes, one at a time | Forcing it if the vendor wizard is open |
| Security suite | Only when replacing it | As part of a junk batch |
| Windows components | No | Even if they appear in an extended list |

Stay at the keyboard for the first batch. Silent flags fail often enough that an unattended queue will stall on a dialog and look frozen.

## Leftovers

After each product, leftovers should name that product. Shared runtimes, documents, and download folders are declines. A monitored install can be more specific; an unmonitored one is a guess. Treat the guess as guilty until the path is obvious. Disk space is not worth a folder you only half recognize.

Reboot between driver-like products. Do not batch a virtual drive, a VPN, and a GPU utility together and then look for a single explanation if the PC comes back wrong.

## Steps

1. Decide whether this PC should keep install monitoring.  
2. If yes, enable it before the next setup, not after.  
3. Select programs by name, not by a sweep of unfamiliar rows.  
4. Run uninstallers where you can answer prompts.  
5. Accept leftovers only for matching paths.  
6. Reboot once at the end if any selection included a driver or shell extension.

## Requirements

| Item | Minimum | Recommended |
|---|---|---|
| OS | Windows versions CrystalIdea supports | Current 64-bit Windows |
| Rights | Administrator for per-machine apps | A note of what you removed |
| Disk | Small install | Monitoring logs stay modest if you do not keep years of them |
| Network | Not required for the local list | Vendor removers may need it |
| Audience | The person who maintains this PC | Not a silent lab image |

## Fits and Limits

It fits enthusiasts and small offices who install desktop tools regularly and want a cleaner exit. It fits a refurbisher less well than a portable bulk uninstaller they do not leave behind. It does not fit Store app removal, license-seat release, or a PC that is compromised. An install list is not a detection log.

Force-style cleanup of a broken entry may exist for dead uninstall strings. Use it when the file is missing, then check services. Do not use it to skip a wizard.

## Fixes

Monitoring missed a setup. It was off, or the setup ran as another user. The later leftover pass will be generic.  
A batch stalled. A dialog is waiting. Finish it before you start a second queue.  
Leftovers look like half of AppData. Stop. That is not one product.  
A program remains. It has a second entry or a Store package. Remove that copy where it was installed.  
The monitor is still running on a PC you only visited. Uninstall Uninstall Tool itself before you leave, unless the owner asked to keep it.
